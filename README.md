# 938W | Blaze Robotics

938W is a VEX V5RC team from Blaze Robotics Academy.

This repository contains the work behind our robot (s), including code, CAD, designs, and documentation. We use it to keep track of our development throughout the season and to hold previous versions of our work. Currently, this repository is CLOSED SOURCE for privacy reasons.

## What you'll find here

- Robot and autonomous code
- CAD models and assemblies
- Mechanical designs and prototypes
- Engineering documentation
- Tools and utilities used by the team

Our CAD and code are developed alongside the physical robot, allowing us to test ideas, reiterate on old designs, and keep a record of how the robot evolves throughout the season.
